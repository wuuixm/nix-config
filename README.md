# Gardenia NixOS Configuration

[**中文版**](README-CN.md)

A NixOS configuration built with Flakes, integrating Home Manager for user environment management, using agenix for secrets, and a hybrid desktop setup (niri + Noctalia + COSMIC).

![fastfetch](https://github.com/wuuixm/img-bed/blob/main/nixos/fastfetch.png)

## Project Structure

```
├── flake.nix                      # Entry point – defines Gardenia config & dependencies
├── flake.lock                     # Locked dependency versions for reproducibility
├── hardware-configuration.nix     # Auto-generated by nixos-generate-config
│
├── os-modules/                    # NixOS system modules (auto-imported)
│   ├── boot/                      # GRUB, kernel params, zram
│   ├── desktop/                   # niri, Noctalia, Ly display manager, portals
│   ├── hardware/                  # PipeWire, NVIDIA Prime, asusd, bluetooth
│   ├── locale/                    # Timezone, locale, fcitx5, fonts
│   ├── nix/                       # Flakes, GC, nix-ld, optimisation
│   ├── services/                  # SSH, NetworkManager, Flatpak, Steam, Docker
│   ├── users/                     # User "wuuixm" definition
│   └── virtualisation/            # libvirtd + virt-manager
│
├── hm-modules/                    # Home Manager modules (auto-imported)
│   ├── default.nix                # Entry: username, XDG dirs, env vars, base packages
│   ├── agenix/                    # Secret management (aria2-rpc-secret, github-token)
│   ├── aria2/                     # Aria2 downloader with systemd service
│   ├── btop/                      # btop system monitor
│   ├── evil-helix/                # Helix editor (evil-helix fork)
│   ├── fastfetch/                 # System info (neofetch alternative)
│   ├── fish/                      # Fish shell (vi-bindings, abbreviations)
│   ├── ghostty/                   # Ghostty terminal (custom shaders)
│   ├── git/                       # Git config with GitHub OAuth
│   ├── lazygit/                   # LazyGit TUI (delta diff pager)
│   ├── neovim/                    # Neovim (oil.nvim, fzf-lua, catppuccin)
│   ├── niri/                      # niri compositor raw config
│   ├── noctalia/                  # Noctalia desktop shell
│   ├── opencode/                  # OpenCode AI coding assistant
│   ├── rime/                      # RIME (fcitx5) Shuangpin input schema
│   ├── starship/                  # Starship prompt
│   ├── tealdeer/                  # tealdeer (tl;dr for commands)
│   ├── yazi/                      # Yazi terminal file manager
│   └── zed/                       # Zed editor
│
├── tools/
│   └── edit-password              # Interactive agenix secret manager (Python polyglot)
```

## Tools

### edit-password

A self-contained Python (polyglot) script for interactively managing agenix encrypted keys – supports adding, editing, and deleting public keys and passwords, with automatic backup snapshots.

```bash
cd ./tools
./edit-password
```

## Tips

### Fish Auto-Generated Abbreviations

`hm-modules/fish/default.nix` iterates all directories under `hm-modules/` and automatically generates `i<module_name>` abbreviations for opening each module's config in one keystroke.

- `ifish` → opens fish config
- `igit` → opens git config
- `iniri` → opens niri config
- … and similarly for all modules.

### Auto-Import Module Discovery

`os-modules/default.nix` and `hm-modules/default.nix` use `builtins.readDir` to automatically import all subdirectories. To add a new module, simply create a new directory – no manual import edits needed.

### NixOS Secrets Unified Management

`tools/edit-password` uses a polyglot technique (the same file runs as both shell and Python), providing interactive CRUD for agenix keys with automatic backup snapshots and one-key rollback.
