# Gardenia NixOS Configuration

[**中文版**](README-CN.md)

A NixOS configuration built with Flakes, integrating Home Manager for user environment management, agenix for encrypted secrets, and a hybrid desktop setup (niri + Noctalia + COSMIC) on an ASUS ROG laptop (AMD GPU + NVIDIA Prime).

![fastfetch](https://github.com/wuuixm/img-bed/blob/main/nixos/fastfetch.png)

## Usage

### Prerequisites

- NixOS with Flakes enabled
- SSH key at `~/.ssh/id_ed25519` (used as the agenix identity)
- Run `./tools/edit-password` before the first switch to generate the age secrets

### Rebuild

```bash
# switch system (hostname: Gardenia)
sudo nixos-rebuild switch --flake ~/nixos-Gardenia#Gardenia

# update all flake inputs
nix flake update --flake ~/nixos-Gardenia
```

Fish provides short abbreviations for these (`hm-modules/fish/default.nix`):

| Abbr | Command |
|------|---------|
| `rd` | `sudo nixos-rebuild switch --flake ~/nixos-Gardenia#Gardenia` |
| `upd` | `nix flake update --flake ~/nixos-Gardenia` |
| `gc` | `nix-collect-garbage -d && sudo nix-collect-garbage -d` |
| `ips` | `~/nixos-Gardenia/tools/edit-password` |
| `ifk` / `ihm` / `ish` | open `flake.nix` / `hm-modules/default.nix` / fish config in `$EDITOR` |
| `i<module>` | open any hm module config (auto-generated for every module dir) |
| `nrs` / `zed` / `bp` / `ff` | `niri-session` / `zeditor` / `btop` / `fastfetch` |

## Tools

### edit-password

A self-contained Python (polyglot) script for interactively managing agenix encrypted keys – supports adding, editing, and deleting public keys and passwords, with automatic backup snapshots.

```bash
cd ./tools
./edit-password
```

## Tips

### Fish Auto-Generated Abbreviations

`hm-modules/fish/default.nix` iterates all directories under `hm-modules/` and automatically generates `i<module_name>` abbreviations for opening each module's config in one keystroke.

- `ifish` → opens fish config
- `igit` → opens git config
- `iniri` → opens niri config
- … and similarly for all modules.

### Auto-Import Module Discovery

`os-modules/default.nix` and `hm-modules/default.nix` use `builtins.readDir` to automatically import all subdirectories. To add a new module, simply create a new directory – no manual import edits needed.

### NixOS Secrets Unified Management

`tools/edit-password` uses a polyglot technique (the same file runs as both shell and Python), providing interactive CRUD for agenix keys with automatic backup snapshots and one-key rollback.
